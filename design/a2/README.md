# 慢记 · 视觉重做 02「晨光」

> 针对反馈：“这和我之前的一模一样。”
>
> 上一版（`design/a/`）改的是结构，但视觉 DNA 还是原来的：米纸、朱砂、宋体标题、印章、细线。这一版保留讲述结构与适老约束，**把视觉语言整个换掉**。

- 方案预览：[`index.html`](index.html)
- 对比图：[`previews/compare.jpg`](previews/compare.jpg)
- 单屏：[`previews/`](previews/)

## 一、这次换掉了什么

| 维度 | 旧版 / 现有 | 新版「晨光」 |
| --- | --- | --- |
| 颜色 | 米纸 `#F6F1E8` + 朱砂 `#D86545` | 暖白 `#F6F3EA` + 松绿 `#1E5A48` + 杏色 `#F8E5D6` |
| 字体 | 宋体标题 + 宋体正文 | 苹方黑体标题/按钮/导航；宋体只留给传记正文 |
| 形状 | 细线、小圆角、双线、印章 | 白色卡片、18–26px 大圆角、实心绿色块、999 胶囊 |
| 品牌 | 朱砂“慢”字方印 | 青绿圆角标 + 白色声波；和“小暖在听”同一符号 |
| 导航 | 线框图标 + 小字 | 薄荷色激活胶囊 + 实心绿色“小暖”圆 |
| 信息 | 大标题 + 清单 + 分隔线 | 绿色“接着讲”卡 + 白卡话题 + 状态胶囊 + 进度条 |
| 阅读 | 纸页 + 页眉线 + 印章 | 白色书页卡 + 黑体标题 + 宋体正文 + 悬浮胶囊工具栏 |

**没有换的**：讲述流程（首页 → 准备 → 讲述 → 整理 → 故事 → 传记）、适老尺寸、字号/朗读、自动保存、游客路径。

## 三、颜色与对比度

| Token | 色值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| `--bg` | `#F6F3EA` | 页面底色 | — |
| `--white` | `#FFFFFF` | 卡片、书页 | — |
| `--ink` | `#1C2722` | 正文、标题 | 13.9 : 1（对底色） |
| `--ink2` | `#4F5E57` | 次要信息 | 6.2 : 1 |
| `--muted` | `#5F6D65` | 辅助文字 | 4.9 : 1 |
| `--green` | `#1E5A48` | 主操作、进度、激活 | 白字 8.0 : 1 |
| `--mint` | `#E2EFE8` | 状态底、激活胶囊 | 绿字 6.8 : 1 |
| `--peach` | `#F8E5D6` | 温暖提示、时间卡 | 深棕字 4.6 : 1 |
| `--amber` | `#A1522A` | 提示文字、杏色深色 | 5.0 : 1 |

- 绿色主卡上的白字 8.0:1；浅绿字 5.2:1；白色半透明正文 ≥5.0:1。
- 不用颜色单独表意：状态都带文字（已成篇 / 还没讲 / 已保存）。
- 深绿只出现在主卡、书封和主按钮，面积可控。

## 四、适老约束

- 阅读正文 18.5–19px / 行高 1.85；标题 28–30；辅助 10–12.5。
- 主按钮 58；次按钮 50；设置行 56；底部导航 84；分段控件 44。
- 字号三档 + 朗读仍在“我的”第一组；阅读页底部常驻“Aa”。
- 无横向滚动、无倒计时、无广告；讲述自动保存，暂停/打字常驻。
- 图标全部带文字；颜色只做辅助。
- 新配色对比度均 ≥4.5:1（最浅辅助字 4.9:1）。

---

## 五、下一步

1. **先确认视觉方向**：这套青绿/杏色/黑体是否够“新”，又不失温度。
2. 若确认，补齐剩余 6 屏（欢迎、登录、整理、故事、记录、家人）+ 桌面阅读。
3. 再进 Vue：先 tokens + 首页 + 讲述 + 阅读三屏，真机跑 390 / 430 / 1280。

如果觉得绿色偏“健康 App”，可以保留这套形状与字体，只换主色：
- 靛蓝 + 珊瑚 + 暖白
- 暖棕 + 奶油 + 橄榄
不建议再回到“米纸 + 朱砂 + 宋体标题 + 印章”，那是上一版看起来一样的根因。
