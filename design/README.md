# 慢记 · UI 重设计 / 过程记录

> 目标：给「慢记」重新做一套界面设计——保留“陪长辈慢慢聊，写成一本人人传记”的产品内核，让讲述更敢开口，让传记更像一本书，让家人愿意读。

> **可直接点的原型：** [`design/prototype/index.html`](prototype/index.html)（三版切换 + 共用年轮语音页，单文件，双击打开）。

> **2026.11.10 最新｜三版结构探索：** 按“保留原来的颜色、语音通话页沿用年轮访谈、重新出三版”的要求，当前请看 [`design/three/index.html`](three/index.html) 与 [`design/three/README.md`](three/README.md)。三版共用年轮语音页，只改入口与版式。

> 过程稿：`a/`（纸墨书卷）与 `a2/`（青绿晨光）已不采用；本文件保留第一阶段的审计与调研，作为记录。

本目录保留现状审计、参考资料与各轮过程稿；**当前方案在 `design/three/`**。

## 一、先看现在的界面

| 页面 | 现状 |
| --- | --- |
| 人生轨迹 | `audit/before-home-mobile.jpg` |
| 讲述 / 小暖 | `audit/before-interview-mobile.jpg` |
| 传记阅读（手机） | `audit/before-reading-mobile.jpg` |
| 传记阅读（桌面 1280） | `audit/before-reading-desktop.jpg` |
| 人生轨迹（桌面 1280） | `audit/before-home-desktop.jpg` |

### 做对了的地方

- 米纸底色 + 朱砂红的主色方向是对的：温暖、不医疗、不说教，和“传记”是同一气质。
- 宋体标题 + 大留白，已经有一点书的味道。
- 主流程清晰：选话题 → 讲 → 整理 → 读；底部常驻“小暖”，符合“随时能讲”的产品定位。
- 页面数量不多，组件是手写的，改造成本可控。

### 主要问题

1. **像“纸色后台”，不像“一本书”**：标题、卡片、列表的操作感太重；缺少封面、章首页、页码、目录这些“书”的线索。
2. **第一屏没有情绪入口**：一上来是“人生轨迹”大标题 + 话题清单，用户不知道“讲这些会变成什么”。
3. **讲述页太空、主动作太弱**：首屏约 60% 是空的；主按钮“开始讲述”是浅米色，看起来像禁用；没有“可以打字 / 可以先停 / 录音怎么处理”的说明，长辈会犹豫。
4. **字号与对比度不够适老**：正文 17–18px 尚可，但辅助信息 11–13px 偏多；部分浅棕文字在米色底上低于 4.5:1；底部导航文字 12.5px，偏小。
5. **状态与进度缺失**：没有“传记完成到哪了”“这段来自哪次讲述”“这一章还差几段”，讲完的收获感弱。
6. **桌面只是把手机版拉宽**：1280 宽度下正文一行约 40 个汉字，阅读疲劳；底部导航横跨全屏，和内容没有关系。
7. **视觉细节不统一**：圆角 5/8/10/12/14/16 混用；字号层级靠零散数值（11.5/12.5/13.5/15.5/17/21/27/28）；同一“返回”有 `<`、`‹`、文字三种写法。
8. **“家人”还是一个空占位**：但它可能是这个产品最重要的传播与共读场景，值得在视觉上先给出位置。

> 注：之前有一次截图显示登录页右侧被裁切，经 390px 移动端仿真复核，是截图方式造成的假象，**登录页本身没有溢出问题**。

## 二、参考资料（“找找”的部分）

### 1. 气质：Warm & Editorial

[PageProofer · Warm & Editorial](https://pageproofer.com/inspiration/warm-editorial/) 总结了 Readwise、Every、Stripe Press、Are.na 等站点的做法，可以直接借用的规则：

- 暖白纸面 `#f9f7f5–#fdfaf7` 打底，白色只留给卡片和“产品本身”。
- 文字用暖调墨色，不用纯黑；阴影也带墨色。
- 标题要么“大而轻的衬线”，要么“大而重的无衬线”，不要中间态。
- 一个强调色，只给 CTA、链接、激活态；其余全部是纸与墨。
- 分隔用细线、点线、手绘线，而不是色块分区。
- 正文 17–20px、行高约 1.5、行宽控制在 600–830px（中文约 28–36 字）。
- 真正的产品界面比插画更有说服力。

对慢记的启发：**把“传记”真正做成界面里的主角**，而不是一个叫“传记”的 Tab。

### 2. 可用性：适老化规范

[微信长辈就医适老化设计规范](https://developers.weixin.qq.com/doc/service/guide/product/elderMedical/elderMedical-designstandards.html)（依据工信部《移动互联网应用（APP）适老化通用设计规范》）给出了可执行的硬指标：

- 主要文字不小于 **18pt**，适老版最大字体可达 **30pt**；标准版可按 **1.4 倍**放大。
- 正文行距 ≥ **1.3 倍**，段间距要大于行距。
- 文本对比度 ≥ **4.5:1**；大于 18pt 的文字 ≥ 3:1。
- 主要可点区域 ≥ **44×44**，适老版主操作 **60×60**。
- 建议无衬线字体，并提供字号调节。
- 重要操作要放大、首屏可见；避免复杂手势和多步验证。
- 图标按钮要配文字说明；文字尽量完整显示，不要省略。

对本项目的结论：讲述页是“长辈单人操作”的核心场景，应按**适老版**标准做（大字号、大按钮、强对比、可随时暂停）；首页和传记可以更“正常”一些，但正文不低于 17px。

### 3. 产品参照：把“问答”变成“书”

- [Storyworth](https://welcome.storyworth.com/what-is-storyworth)：每周一个问题、可以打电话口述、不需要登录、最后印成精装书；家人可以选问题、收故事。
  - 启发：**降低开口门槛**比增加功能重要；“成书”是最强的长期动机。
- [Remento](https://www.remento.co/)：以“保留家人的声音和故事”为核心，录音 + 转写 + 成册，强调家庭共同参与。
  - 启发：**声音本身是纪念物**，界面要让人觉得“说的话被好好收着”。
- [Envato · 2026 UI 趋势](https://elements.envato.com/learn/ux-ui-design-trends)：平静界面、透明的 AI、减少视觉戏剧化。
  - 启发：AI 不要抢戏；讲述时让“小暖在听”成为唯一焦点。

### 4. 中文排版

- 标题与正文用宋体（Songti SC / 思源宋体），界面标签、按钮、表单用苹方/思源黑体。
- 中文正文行高 1.8–2.0；段首缩进 2 字符；行宽 28–32 字最舒服。
- 数字、页码用 Georgia / Iowan Old Style 这类有旧书感的衬线，和宋体更搭。

## 三、三个方向

每个方向都在 `concepts/index.html` 里，含手机实尺寸稿（390×844）与色彩/字体说明。

### A. 纸墨 · 一册手稿（推荐）

**一句话**：界面就是一本正在被写下的书。

- 视觉：宣纸底、墨色字、朱砂印章、双细线、中文页码、首字下沉。
- 信息架构：首页从“话题清单”变成“章内页目”；顶部直接显示“这一章 5/12”。
- 关键页面：首页 + 传记阅读。
- 适合：阅读体验、适老、品牌可信度。
- 风险：偏静、偏传统；需要用真实照片和家人的声音把它“暖”起来。

![方向 A](previews/direction-a.jpg)

### B. 灯火 · 夜里的慢谈

**一句话**：讲述时，世界只剩一盏灯和您的声音。

- 视觉：墨夜底、米白字、琥珀色灯火、呼吸的光晕、字幕先于界面。
- 信息架构：讲述页去掉所有导航，只保留“小暖的问题 / 您说的话 / 说完了”。
- 关键页面：夜间首页 + 讲述中。
- 适合：语音访谈的沉浸感、差异化、品牌记忆点。
- 风险：深色对白内障与老花不友好，**不能做默认主题**；建议作为“夜听模式”，并保证正文 ≥ 7:1 对比度。

![方向 B](previews/direction-b.jpg)

### C. 家书 · 会收照片的相册

**一句话**：一张老照片，比十个问题更能让人开口。

- 视觉：米纸、胶带、拍立得、楷体手写批注、入册印章、家人回话。
- 信息架构：以“故事卡 + 照片”组织首页；故事页就是一张可以读给孙辈听的相册页。
- 关键页面：故事首页 + 故事页（含家人回话）。
- 适合：家庭共读、分享传播、情感浓度。
- 风险：装饰多，容易乱；依赖照片上传与家人评论能力，否则会变成空壳。

![方向 C](previews/direction-c.jpg)

## 四、当前：三版结构探索

已按新要求重做：保留原来的米纸/朱砂，语音通话页沿用年轮访谈，重新做三版结构（年轮时间轴 / 每日一页 / 小暖对话）。完整方案见 [`design/three/index.html`](three/index.html)。

- **A「纸墨」**（`a/`）：结构改了，但视觉 DNA 仍是原来的纸墨书卷，被指出“一模一样”，不采用。
- **A2「晨光」**（`a2/`）：换了青绿视觉，但颜色不是原来的，且入口结构没有真正换，不采用。
- **三版探索**（`three/`）：原色 + 年轮语音页 + 三种入口，作为当前可选的三个方向。

## 五、落地时先定下的基础规范（草案）

| 项 | 规范 |
| --- | --- |
| 栅格 | 390 设计宽；左右边距 24；8pt 间距体系（4/8/12/16/24/32/48） |
| 字体 | 标题/正文：Songti SC（思源宋体）；UI：PingFang SC（思源黑体）；数字：Georgia |
| 字号 | 章标题 30/42；页面标题 24/36；正文 17–18/32–34；辅助 14/22；最少 12（仅角标） |
| 颜色 | 纸 `#F5EDDF`、墨 `#2B241D`、朱砂 `#A9472B`、赭石 `#97713F`、松烟绿 `#4F6A58`；全部过 4.5:1 |
| 触控 | 主操作 ≥ 56 高；列表行 ≥ 64；图标按钮 ≥ 44×44，且带文字 |
| 阅读 | 中文行高 1.9–2.0；行宽 28–32 字；首行缩进 2 字；段间距 ≥ 行高 |
| 反馈 | 讲述中永远可见“小暖在听 / 已保存”；结束整理必须给出“已收好”的明确回执 |
| 无障碍 | 支持“大字模式”（整体 1.25×）；尊重 `prefers-reduced-motion`；不为唯一信息使用颜色 |
