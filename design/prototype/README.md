# 慢记 · 三版可点原型

**直接双击 `index.html` 就能点。** 样式和交互都在这一个文件里，不需要服务器、不需要构建、没有后端。

---

## 怎么点

顶部三个 tab 切换版本：**V1 年轮 / V2 每日一页 / V3 小暖对话**。

### V1 年轮
- 点“接着讲”或任一话题 → 年轮语音页
- 点“传记” → 年轮书封
- 点“继续读” → 阅读页；点“Aa” → 字号
- 语音页“结束” → 直接打开书页

### V2 每日一页
- 点“开始讲” → 年轮语音页
- 点“换一个话题” → 话题签；选一个，首页问题会更新
- 点“读这一页” / “去读” → 日记式阅读页
- 语音页“结束” → 打开书页

### V3 小暖对话
- 点三个建议 → 换一个问题并进入语音页
- 点“按住说话” → 语音页
- 点“传记”或“看看我的传记” → 书页
- 阅读页有一条小暖批注；“继续补充”回到语音页

### 语音页（三版共用）
- 左上返回：回到进入前的页面
- “暂停” ↔ “继续”：状态、字幕和按钮会变
- “结束”：打开当前版本的书页，并提示“故事已收进第一章”

### 字号
- 阅读页右上“Aa”→ 标准 / 大 / 特大
- 特大字号下，阅读区可以上下滑动；底部操作固定

---

## 颜色与边界

- 原色：米纸 `#F6F1E8`、墨 `#2E2925`、朱砂 `#D86545`。
- 按钮和小字用深一级朱砂 `#B24E34`，保证白字 5:1；装饰仍是原来的朱砂。
- 语音页沿用“年轮访谈”：同心圆、居中麦克风、字幕、底部暂停/结束两个圆形操作；三版不改结构。
- 没有后端，所有数据是示例；点到还没做的页面会出现“正式版补齐”的提示。
