## 一、这套方案解决什么

1. **长辈不知道下一步做什么** → 一屏一个主操作，按钮写结果（“接着讲”“开始讲这段”“说完了，帮我整理”）。
2. **第一次开口紧张** → 增加准备页，先讲清三步、时长、保存和隐私；语音与打字并列。
3. **讲完没有回声** → 整理完成就是一页故事；故事页写明“来自哪次讲述”“已收进第一章”“传记第 12 页”。
4. **传记不像一本书** → 封面 → 目录 → 章页；宋体正文 19px、行高 1.84、页码、修订印章。
5. **老花眼读不动** → 标准/大/特大三档 + 朗读；默认推荐“大”。
6. **桌面只是拉宽** → 目录 + 书页 + 进度三栏，正文每行 28–30 字。

**和旧版的关系**：A 不是给原页面换字体。去掉横向时间轴、空白的麦克风首屏、直接进入正文的传记，换成“接着讲卡片 + 章节条 + 页目”“准备页 + 浅色聆听态”“封面 + 目录 + 章页”。B（深色）与 C（照片相册）不采用：深色对白内障/老花不友好；照片是加分项，不能承担结构，没有照片的用户会看到空相册。

## 三、视觉系统

### 颜色（WCAG 2.1 实测）

| Token | 色值 | 用途 | 对比度（对 #F7F1E6） |
| --- | --- | --- | --- |
| `--paper` | `#F7F1E6` | 页面底色 | — |
| `--sheet` | `#FFFCF5` | 书页、输入框 | — |
| `--ink` | `#27211B` | 正文、标题 | 14.2 : 1 |
| `--ink-2` | `#5A5046` | 次要信息 | 7.0 : 1 |
| `--muted` | `#73675A` | 辅助文字（≥14px） | 4.9 : 1 |
| `--accent` | `#A8432A` | 主操作、当前章、印章 | 5.3 : 1 |
| `--gold` | `#8A673C` | 章节号、页码 | 4.6 : 1 |
| `--sage` | `#4E6A57` | 已保存、成功 | 5.3 : 1 |
| `--wash` | `#EFE4D2` | 提示底、引文底 | — |

- 白字在朱砂上 6.0 : 1。
- 朱砂只用于主操作、当前章、印章；不用它做满屏装饰。
- 颜色不作为唯一信息：状态同时有文字（“已成篇”“待整理”“已保存”）。

### 字体

- 标题、阅读正文：Songti SC / 思源宋体。
- 按钮、标签、表单、导航：PingFang SC / 思源黑体。
- 数字、页码：Georgia Italic。

| 用途 | 字号 / 行高 |
| --- | --- |
| 章标题 | 30 / 42 |
| 页面标题 | 24–28 / 36–40 |
| 正文 | 17 / 28 |
| 阅读 | 19 / 34（1.84） |
| 辅助 | 14 / 22（最小 12，仅角标） |
| 导航标签 | 13 |

### 间距与触控

- 8pt 体系：4 / 8 / 12 / 16 / 24 / 32 / 48。
- 左右页边距 24；卡片内边距 16。
- 主按钮 60；次按钮 54；列表行 ≥72；底部导航 82；图标按钮 ≥44×44，全部带文字。
- 圆角：控件 10–12；纸面 2–4；不使用大圆角卡片。
- 动效 ≤240ms；尊重 `prefers-reduced-motion`。

### 大字模式

- 标准 19 / 大 23 / 特大 27（相对标准 1.0 / 1.21 / 1.42）。
- 只放大正文与按钮，不放装饰；默认推荐“大”。
- 设置位置：“我的 → 阅读与听觉”第一组；阅读页底部常驻“字号”。

## 四、状态清单

| 对象 | 状态 | 界面反馈 |
| --- | --- | --- |
| 话题 | 还没讲 / 讲到一半 / 整理中 / 已成篇 / 整理失败 | 文字标签 + 行内操作（继续讲 / 继续整理） |
| 讲述 | 准备 / 在听 / 暂停 / 思考 / 没听清 / 结束 | 状态条、波形、实时字幕、主按钮 |
| 保存 | 已保存 / 正在保存 / 网络不稳 | 常驻“已自动保存”；网络问题不丢内容 |
| 整理 | 已保存 / 分成段落 / 正在写成故事 / 完成 / 失败 | 三步状态；“离开也会保存”；失败可重试 |
| 分享 | 未分享 / 已邀请 / 已读 / 有留言 | 只读链接、家人回话，不做已读压力 |
| 空状态 | 没有故事 / 没有录音 / 没有网络 | 一句人话 + 一个动作，不放插画占位 |

**原则**：失败不吓人（“这次没整理好，您说的话都还在”）；等待有进展（“分成 3 段 → 正在写成故事”）；暂停是正常操作，不是失败。

## 五、适老与无障碍验收

- [ ] 正文 ≥19px；按钮 18px；辅助文字 ≥12px 且不承载关键信息。
- [ ] 文本对比度 ≥4.5:1；大字 3:1；已按上表实测。
- [ ] 主操作 60×≥60；次操作 54；列表 ≥72；图标按钮 ≥44×44 且有文字。
- [ ] 字号三档可调，选择被记住；不只依赖系统字号。
- [ ] 无横向滚动；章节、话题、记录全部竖排。
- [ ] 无倒计时、无广告、无诱导分享；不因超时清空。
- [ ] 自动保存每一轮讲述；暂停、返回、关闭页面都不丢。
- [ ] 语音之外始终有“改用打字”；不强迫授权麦克风。
- [ ] 焦点可见（2px 朱砂描边）；键盘可完成登录、翻页、字号切换。
- [ ] 动效 ≤240ms，尊重减少动效；不使用闪烁、快速缩放。
- [ ] 朗读可中断、可继续；朗读时高亮当前段落（实现阶段）。
- [ ] 所有错误都有文字说明和下一步动作，不只变红。

## 八、需要产品确认的 5 件事

1. **朗读**：用系统 TTS，还是接云端语音？前者零成本、可离线；后者音色更温暖。
2. **字号存储**：建议本地 + 账号同步；换手机后仍保留“大”。
3. **家人分享**：只读链接 + 留言，首版是否要留言？若暂不做，故事页与家人页的回话位先隐藏。
4. **游客草稿**：现有逻辑登录后不自动合并；本方案文案按“不合并”写。若要做合并，需要迁移策略。
5. **照片**：保留为可选补充（故事页可加一张），不做相册骨架；没有照片的页面也成立。
