| 约束 | 做法 |
| --- | --- |
| 颜色用之前的 | 米纸 `#F6F1E8`、墨 `#2E2925`、朱砂 `#D86545`；按钮/小字加深到同一朱砂的 `#B24E34`，保证白字 5:1 |

颜色与字号没有为了“新”而牺牲可用性：阅读正文 18.5–19px、行高 1.86，最浅辅助字 ≥4.9:1，主操作 54–58px。

## 二、共用：年轮语音通话页

三版都进入同一张页：

- 顶部只有一个返回箭头，没有标题和 tab。
- 居中 `小暖` 32px，下面一行“小暖正在听您讲话”。
- 三圈金色细线（`#BC9C65`）+ 中心麦克风；中间一圈有极淡的底色。
- 字幕在圆下，19–20px 宋体，两行以内。
- 底部只有两个圆形操作：暂停（米色圆）和结束（深朱砂圆），标签在圆下。
- 不显示切换/分享/设置，避免在通话中堆功能。

唯一调整：结束圆按钮的朱砂加深到 `#B24E34`，白字从 3.4:1 提升到 5:1；小字颜色略加深。其余保持原样。

## 三、三个版本

### V1 年轮 · 生命时间轴

**一句话**：把一生竖着摊开，一圈一圈往下走。

- 首页：竖向时间轴，少年 / 青年 / 中年 / 如今；每个阶段一个年轮节点。当前阶段展开“接着上次”和话题，其余收起。
- 选话题：在当前阶段里展开，读完一段再往下。
- 传记：年轮书封（同心圆徽记、无印章）+ 章节环点 + “继续读”。
- 导航：5 项，中心“小暖”是空心环，和语音页同构。
- 适合：想先看一生全貌、喜欢“年轮/成长”隐喻的人。
- 风险：时间轴较长；要靠“当前阶段展开”控制一屏信息量。

### V2 每日一页 · 今日一问

**一句话**：不先看目录，每天只出现一个问题，像翻一页日历。

- 首页：日期 + 今日一问 + “开始讲”；“换一个话题”打开话题签；下面是“昨天写下的”和“您的传记”入口。
- 选话题：不把 100 个话题铺在首页；从“换一个话题”进入。
- 传记：日记式阅读页，日期在章节标题之上。
- 导航：4 项（今天 / 传记 / 小暖 / 我的）；家人放在“我的”。
- 适合：喜欢安静、每天只聊一点、不想做选择的人。
- 风险：话题发现弱；首页必须保留“换一个话题”，否则会被困在今天这一题。

### V3 小暖 · 对话入口

**一句话**：没有菜单，首页就是和小暖的一段对话。

- 首页：昨天的一句收尾 + 今天小暖的问候 + 三个大建议 + “上次说到” + “看看我的传记”。
- 选话题：在对话里点三个建议，或往上翻“传记”。
- 语音：底部“按住说话”直接进入年轮页；没有 tab bar。
- 传记：书页 + 小暖批注（“这句话我记下了……”）。
- 适合：不想选菜单、希望有人陪着说、对聊天熟悉的人。
- 风险：聊天感最强、书感最弱；靠阅读页的批注和“看看我的传记”把书感补回来。

## 四、为什么这三版算“不同”

不是换色，也不是换字体，而是换**进入讲述的方式**：

| | V1 年轮 | V2 每日一页 | V3 对话 |
| --- | --- | --- | --- |
| 首页入口 | 竖向时间轴 | 今日一问 | 小暖的对话 |
| 选话题 | 展开当前阶段 | 换一个话题 / 话题签 | 对话里的三个建议 |
| 导航 | 5 tab + 中心空心环 | 4 tab，无浮钮 | 顶部传记/我的 + 按住说话 |
| 语音页 | 共用年轮页 | 共用年轮页 | 共用年轮页 |
| 气质 | 回望一生 | 安静的日常 | 有人陪着 |

三版都保留了适老底线：无深色主界面、无照片骨架、无横向滚动、无倒计时；自动保存、可暂停、可打字、字号三档 + 朗读仍在。
